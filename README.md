Why Grace thinks git is cool:

You can have a directory (like a folder, which holds all of your work things - data, data dictionary, manuscript drafts, plots, etc) on your laptop, that you can update as you like but with a documented history of these changes! You can upload them to GitHub (here) whenever you have a version that you are happy with (you can always change it in the future). You can work with collaborators on this, too! If I had ran some analysis, maybe a simulation study, the results can be generated into this directory - without you ever working on them yourself. You can share code in here, run code from this directory, etc.
